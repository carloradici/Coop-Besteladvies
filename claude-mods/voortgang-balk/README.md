# voortgang-balk
Kleine balk boven het tekstveld. Links staat hoe ver Claude is met bouwen (balkje plus procenten), gelezen uit regels als "⏳ 40% · nu testen" in Claudes berichten; aan het eind van een beurt springt hij op 100% klaar. Rechts staat hoeveel Claude-gebruik je nog over hebt in het 5-uursvenster en de week, met de tijd tot de reset. Claude krijgt zelf de instructie om die voortgangsregels te schrijven.

## Installeren
Staat al aan in elke Claude-sessie met de repo Coop-Besteladvies of Broodkarren (via `.claude/settings.json`). Elders, in een terminal:

`/plugin install voortgang-balk --marketplace carloradici/Coop-Besteladvies`
